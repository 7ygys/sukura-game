# 参考图拆解（Steam 版对战画面）

> 来源：用户提供的实机截图（`furuyoni_digital`，2800×1260）
> 用途：复刻结构与光影，**不复制美术**（全部用代码画）

---

## 1. 视角与构图

- **俯视约 60–70°**：既看得到屋顶正面，也看得到大片地面
- **建筑只占顶部 1/3**：中央社殿 + 左右回廊 + 左右各一座塔楼
- **地面占 2/3**，是视觉主体 —— 这点和我的 v2/v3 完全相反（我把天空放上半屏，结果对称过去的对手跑天上去了）

## 2. 关键元素与位置

| 元素 | 位置 | 说明 |
| --- | --- | --- |
| 中央社殿 | 顶部正中 | 大歇山瓦顶 + 朱红柱 + 白墙 + 石阶下行 |
| 左右回廊 | 顶部两侧 | 白墙 + 朱柱 + 长屋顶 |
| 左塔 | 左上 | 深色（黑瓦），二层，带窗与栏杆 |
| 右塔 | 右上 | 浅色（白墙黑瓦） |
| **巨大石环** | 地面正中 | 同心圆 + 放射分割线，嵌在地面里 |
| **蛇形踏石** | 中轴纵向 | 约 8–10 块浅蓝椭圆石，从下往上通向社殿石阶，**有轻微 S 弯** |
| 樱树 | 四周（上、左、右、下四角） | 花团成片，柔边 |
| **铺地花瓣** | 满地 | 不只是飘落的，**地面上铺了厚厚一层**，这是氛围的关键 |

**特点：UI 全部贴边，中间大片留给场景。** 这跟我的 v4 把东西堆在右下角完全不同。

## 4. 可以偷师的技巧

1. **地面铺花瓣**：比"空中飘几片"有效十倍，一眼就有季节感。
2. **巨大石环**：给了中心一个"场"，视线自然收拢。
3. **蛇形踏石**：比直线更有生命感，也更能暗示"距离"是可以被推拉的。
4. **建筑压在上缘**：既有纵深，又不抢戏。
5. **柔边花团**：用多层半透明圆堆出来，不用描边——这就是"写实但不照片"的关键。

## 5. 与我们的设计差异

| 项 | 参考图 | 我们的想法（D27） |
| --- | --- | --- |
| 中心 | 石环（干地） | **浅水潭**（有水、有涟漪） |
| 间合 | 蛇形踏石 | 10 块石桥（纵向） |
| 装 | 地面上的盘 | **五角石桌** |
| 命 | 左上角红盘 | **挂在樱枝上的 10 颗结晶** |
| 气 | 左上金色盘 | **大灯笼** |
| 氛围 | 明亮粉白（昼/黄昏） | **明亮夜色、蓝紫** |

> 结论：**结构可以学，风格要各走各的**。参考图是"白天樱花庭院"，我们做的是"夜樱庭院"。

## 6. B 方案落地（v6，2026-10-30）

用户选定 **B：搬结构、走夜景**。v6 的取舍：

| 从参考图拿来的 | 保留我们自己的 |
| --- | --- |
| 建筑压在顶部 1/3 | 色调：**夜樱（蓝紫 + 月光 + 暖灯）** |
| 地面为主，铺满落花 | 中心：**圆形浅水潭**（不是干石环）+ 涟漪 |
| 中心巨大石环 | 间合：**10 块纵向蛇形踏石**跨水 |
| 四角樱树、柔边花团 | 装：**五角石桌** |
| 蛇形踏石 | 命：**樱枝挂 10 颗结晶** |
| UI 贴边、中间留白 | 气：**树上大灯笼** |
| 底部矮墙 + 鸟居剪影收边 | 手牌/牌库/弃牌/付与位/王牌键（我们的布局） |

**没拿的**：参考图是近 180° 完整对称的构图（上下两半几乎镜像），我们只对**玩家功能区**做 180° 对称，**背景（社殿）只放顶部一座**，底部用矮墙+鸟居收边——避免对手的树长在屋顶上。
