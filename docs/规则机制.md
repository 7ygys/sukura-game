## 1. 一局游戏的三个阶段

```
① 双掌缭乱   选 2 柱女神（不同编号）
② 眼前构筑   从两柱共 22 张里，选 7 张通常札 + 3 张王牌（10 张牌库）
③ 樱花决斗   打
```

> 同编号的异格不能同时选。本项目只做 4 位基础女神的主武器，**异格暂时不做**（D18）。

### 1.1 初始状态

| 项 | 值 |
| --- | --- |
| 间合 | **10** 个结晶 |
| 双方装 | 各 **3** |
| 双方气 | 各 **0** |
| 双方命 | 各 **10** |
| 抽牌 | 各抽 **3** 张 |
| 集中力 | 先手 **0**，后手 **1** |
| 王牌 | 全部「未使用」 |

放置完成后，**双方按顺序可以各做一次调度**：选任意张手牌放回牌库底，再抽等量。

## 2. 回合流程

```
开始阶段 → 主阶段 → 结束阶段 → 交换先手
```

### 2.1 开始阶段

1. 记录「**回合开始时间合**」（本回合所有「相对开始时」的判断基准）
2. 结算所有「开始阶段」的【常时】【展开中】【使用済】效果
3. **默认处理**（每位玩家的第一个回合跳过）：
   - ① 当前玩家 `focus += 1`
   - ② **付与札上每张牌各移 1 个结晶到尘**（移完若某张牌上 0 结晶 → 触发付与札破弃）
   - ③ 当前玩家**可以**重组牌库 1 次
   - ④ 当前玩家抽 **2** 张

### 2.2 主阶段

主阶段开始时，当前玩家**先声明**这回合是「标准行动」还是「全力行动」，然后反复执行：

| 行动类型 | 可以做 | 限制 |
| --- | --- | --- |
| **标准行动** | 使用手牌 1 张 / 使用未使用王牌 1 张 / 基本动作 1 次 / 结束本阶段 | **不能用《全力》副类型的牌** |
| **全力行动** | 使用手牌 1 张 / 使用未使用王牌 1 张 / 结束本阶段 | 两者**各只能用 1 次**，且不能做基本动作 |

> 标准行动每次基本动作都要付成本：**集中力 1** 或 **弃 1 张手牌到伏札**。
> 由卡牌效果带来的基本动作**不付成本**。

### 2.3 结束阶段

1. 结算「结束阶段」的【常时】【展开中】【使用済】效果
2. 默认处理：手牌超过上限（2）时，**弃到 2 张**（弃掉的牌进伏札）

## 3. 卡牌模型

### 3.1 三种卡类型

| types | 官方名 | 特征 | 数据字段 |
| --- | --- | --- | --- |
| `attack` | 《攻击》 | 有适正距离、装伤/命伤 | `range` / `damage` |
| `action` | 《行动》 | 无距离，使用即结算 | `text` |
| `enhance` | 《付与》 | 有「纳」，展开后留在场上 | `capacity` |

### 3.2 两种副类型

| types | 官方名 | 效果 |
| --- | --- | --- |
| `reaction` | 《对应》 | 可以在对手攻击时使用来应对 |
| `fullpower` | 《全力》 | **只能在全力行动中使用**；带「全力化」的效果 |

### 3.3 分类

- **通常札**（`kind: normal`）：7 张，进牌库
- **王牌**（`kind: special`）：3 张，放在「王牌区」，有 `cost`（消费），使用后翻面成「使用済」留在场上

## 4. 三种卡的使用流程

### 4.1 《攻击》

```
1. 公开卡 → 生成「攻击对象」（继承卡的距离/伤害/文本/使用者）
2. 检查适正距离：当前间合 ∈ 适正距离？
   ✗ 失败 → 卡退回原处，攻击消失，视为未使用
3. 支付成本（王牌的消费，从气扣）
4. 卡进入「使用中」，王牌记为「使用中」
5. 执行「攻击结算」（见 §5）
6. 卡离场：通常札 → 弃牌堆；王牌 → 王牌区「使用済」
```

### 4.2 《行动》

```
1. 公开卡 → 支付成本
2. 卡进入「使用中」
3. 结算【使用時】效果（没有标注时，裸文本就是【使用時】）
4. 卡离场（通常札→弃牌堆 / 王牌→使用済）
```

### 4.3 《付与》

```
1. 公开卡 → 支付成本
2. 卡进入「使用中」
3. 「纳入」：从尘或自己的装中取「纳」个结晶，移到使用中并挂在卡上
4. 结算【展開時】效果
5. 卡移到「付与札」区
```

## 5. 攻击结算（9 步，必须严格按序）

| 步 | 处理 |
| --- | --- |
| ⅰ | 被攻击方**可以**从手牌/王牌中选 1 张《对应》牌使用（嵌套结算） |
| ⅱ | 若攻击被**打消** → 攻击失败，移除，结束 |
| ⅲ | 若攻击有「不可避」→ 直接成功；否则**再查一次适正距离**，不满足则失败 |
| ⅳ | 若伤害被**打消** → 跳过伤害，直接到 ⅵ |
| ⅴ | **被攻击方承受伤害** |
| ⅵ | 若【攻撃後】被**打消** → 跳过，直接到 ⅷ |
| ⅶ | 结算所有【攻撃後】效果（按卡面顺序） |
| ⅷ | 移除攻击 |
| ⅸ | 「攻击结算结束」 |

### 5.1 伤害的承受（重点）

伤害写作 `X/Y`：**X = 对装的伤害（削装），Y = 对命的伤害（打点）**。

```
受伤害方二选一：
  选「装」→ 从装移 X 个结晶到尘
  选「命」→ 从命移 Y 个结晶到气
约束：
  · 某一边是 `-` 时，只能选另一边
  · 两边都是 `-` 时，什么都不发生
  · 若装结晶数 < X，则**不能**选「装」
```

**数值上限**：装伤最低 0、**最高 5**（除非有「超克」效果取消上限）；命伤最低 0。

### 5.2 攻击对象的可变项

- `+X/+Y`：只修正攻击，不修正卡
- **距离扩大（近X/远X）**：把适正距离往两头撑开
- **距离缩小（近X/远X）**：把适正距离往内削掉
- **超克**：装伤上限取消
- **对应不可（种类）**：对应时不能选用该类牌
- **不可避**：跳过第二次距离检查

## 6. 付与札与破弃

- 付与牌展开后留在**付与札区**，上面的结晶就是它的「耐久」
- **任何时候**某张付与札上的结晶变成 0 → 触发「付与札破弃」（状況起因，优先结算）：
  1. 结算该牌的【破棄時】效果
  2. 若此时仍 0 结晶 → 通常札进弃牌堆 / 王牌进使用済

## 7. 基本动作（5 种）

| 动作 | 效果 | 限制 |
| --- | --- | --- |
| **前进** | 间合 −1（结晶移到自己的装） | 间合 ≤ 达人距离(2) 时**无效** |
| **后退** | 间合 +1（自己的装移 1 个到间合） | 无 |
| **缠绕** | 尘 → 自己的装 | 装满（5）则无效 |
| **宿命** | 自己的装 → 自己的气 | 无 |
| **离脱** | 尘 → 间合 | 间合 > 达人距离 时**无效** |

> 成本：标准行动里做基本动作，要花 1 集中力 或 弃 1 手牌。

## 8. 结晶移动与箭头效果

卡面箭头写作 `距（2）→ 虚`，含义：**从箭头左边区域移右上方数字个结晶到右边区域**。

| 卡面 | 左 | 数量 | 右 |
| --- | --- | --- | --- |
| 距 | 间合 | (n) | 虚 |
| 虚 | 尘 | (n) | 虚 |

双向箭头 `↔`：方向由发动方选。

## 9. 数值修正的应用顺序（实现时最易错）

**数值类**（伤害、纳、消费等），按此顺序：

```
①代入 → ②交换 → ③乘 → ④除 → ⑤加减 → ⑥规范化
```
- 同一类中的多个修正**同时**应用（代入除外，代入取最小值）
- 代入的优先顺序：①自身效果 → ②非当前玩家持有的对象 → ③当前玩家持有的对象

**适正距离类**，按此顺序：

```
①变更 → ②增减 → ③追加 → ④除去 → ⑤距离扩大 → ⑥距离缩小
```

## 10. 胜负判定

**优先级最高**，任何时刻只要条件满足就立即判定：

1. 双方命都为 0 → **平局**
2. 一方命为 0 → 该方**败北**
3. 效果导致败北 → 该方败北，另一方胜利
4. 效果导致胜利 → 该方胜利，另一方败北

> 「不会败北」/「不能胜利」这类效果会改写判定，本项目 4 位女神暂不涉及。

---

## 11. 焦躁（牌库耗尽）

抽牌时牌库为空 → 触发**焦躁**：该玩家承受 `1/1` 伤害（装 1 或 命 1，自选）。

**牌库重组**：
- 由**规则**引起（如焦躁）→ 先受 1 点命伤
- 由**效果**引起 → 不受伤
- 处理：把弃牌堆 + 伏札中的所有**通常札**洗回牌库

## 12. 给实现的映射

### 12.1 状态结构（建议）

```js
state = {
  // 不需要 seed：双方各洗各的牌，私有区本地维护（见讨论记录 4.4）
  turn: 1,
  activePlayer: 0,            // 0 / 1
  distance: 10,
  players: [{
    life: 10, aura: 3, flare: 0, focus: 0,
    staggered: false,
    hand: [],                 // 手牌
    deck: [], discard: [],    // 牌库 / 弃牌堆
    hidden: [],               // 伏札
    specials: [...],          // 3 张王牌 + 状态
    attachments: [],          // 付与札
    used: [],                 // 本回合已用（终端判定）
  }, { ... }],
  attack: null,               // 攻击对象（结算中）
  log: [],                    // 事件日志（用于重放）
}
```

### 12.2 动作（action）清单

```js
{ type: 'useCard',   player, cardId, index }      // 使用手牌
{ type: 'useSpecial',player, specialIndex }       // 使用王牌
{ type: 'basicAction', player, which }            // 前进/后退/缠绕/宿命/离脱
{ type: 'chooseDamage', player, side: 'aura'|'life' }
{ type: 'reaction',  player, cardId | null }      // 对应 or 放弃
{ type: 'declare',   player, mode: 'standard'|'fullpower' }
{ type: 'endPhase' }
{ type: 'mulligan',  player, cardIds }
```

**只有这几种 action**，联机时传给对方的就是这些。

### 12.3 实现顺序建议

1. 状态 + 结晶移动 + 间合（先能算数）
2. 基本动作 + 回合流程（先能「空打」）
3. 《攻击》《行动》使用（不写效果文本）
4. 伤害承受 + 胜负判定
5. 《付与》+ 破弃
6. 逐张填 44 张卡的效果
7. 联机层
