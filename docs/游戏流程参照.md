# 游戏流程参照（v2 · 已按横屏校正）

> 来源：用户手机录屏截取的 9 张实机画面（版本 2.0.9）
> ⚠️ **v1 校准说明**：截图是**竖屏截的**，但游戏本身是**横屏**，画面内容在截图里被旋转了 90°。v1 把方向读反了，v2 已重写。
> ⚠️ 截图不入库（含官方美术），本文只做文字化描述。

## 0. 四段流程

```
① 开始界面 → ② 选人 → ③ 组卡组 → ④ 对战
```

**桌面端与移动端排版保持一致**（用户指示），只做等比放大，不重新设计布局。

## 2. 选人界面

实机（转正后）：

- 一排/网格的**六边形女神头像**，铺在左侧
- 四块**六边形槽位**分给双方（我方 2 + 对方 2）
- 已选槽位显示立绘 + 「变更 / 移除」
- **有一个「?」头像＝随机选择**（不是锁定位，v1 读错了）

### 我们的方案

```
┌───────────────────────────────────────────────────┐
│  ← 返回                   选人（第 1/2 位）         │
├──────────────────────────┬────────────────────────┤
│  女神头像（六边形网格）     │  我方                   │
│  ◇ ◇ ◇ ◇ ◇ ◇             │  ┌──────┐ ┌──────┐     │
│  ◇ ◇ ◇ ◇ ◇ [?]           │  │ 槽1  │ │ 槽2  │     │
│                          │  └──────┘ └──────┘     │
│  悬停：女神名 + 关键词      │  对方（联机时可见）      │
│                          │  ┌──────┐ ┌──────┐     │
│                          │  │ ?    │ │ ?    │     │
│                          │  └──────┘ └──────┘     │
└──────────────────────────┴────────────────────────┘
```

- 六边形头像保留（`clip-path` 就能做）
- **「?」= 随机**：点了随机填一个空槽
- 悬停显示：女神名 + 专属关键词（决死/八相/连火/境地）
- 已选槽位给「移除」小按钮
- 选满 2 位 → 「下一步」亮起
- **联机时对方选的柱子立刻可见**（Q16 已定）

## 3. 组卡组界面

实机（转正后）：

- 左侧一竖排已选牌
- 中间两列可选卡池
- **灰色=未选，彩色=已选**
- 右侧红色数字 = **选卡倒计时**（我们的**不做计时**，D26）
- 左侧竖排「决斗へ」

### 我们的方案（用户指定：与移动端一致 + 打勾）

```
┌──────────────────────────────────────────────────────┐
│  ← 返回          组卡组      通常札 5/7    王牌 3/3     │
├──────────────────────────────────────────────────────┤
│  通常札（14 选 7）                                       │
│  ┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐          │
│  │斩 ✓││一闪 ││柄击 ✓││居合││身法 ✓││气合││气焰│        │
│  └────┘└────┘└────┘└────┘└────┘└────┘└────┘          │
│                                                      │
│  王牌（8 选 3）                                          │
│  ┌────┐┌────┐┌────┐┌────┐┌────┐                      │
│  │月影 ✓││浦波││浮舟 ✓││天音 ✓││律动│                   │
│  └────┘└────┘└────┘└────┘└────┘                      │
│                                                      │
│  [ 决 斗 ]   ← 7 + 3 都选满才可点                        │
└──────────────────────────────────────────────────────┘
```

- **打勾表示已选**，未选灰、已选亮
- **不计时**（红字倒计时不做）
- 选满后同区其余卡片自动锁灰
- 不做右侧大图预览（用户要求）
- **组卡内容不公开**（Q17 已定）：对手看不到我选了什么，开局才知道牌库

## 4. 对战界面

> ⚠️ **重要变化**：用户打算**自己设计一套战斗场景**，不再沿用游戏版图 → 区域位置会重排。本节的实机描述只作参考，**最终布局待用户给出场景设计（Q19）**。

### 4.1 实机看到的结构（横屏转正后）

| 区域 | 内容 |
| --- | --- |
| 一侧 | 对方角色头像（红色印章样式）、对方集中力、对方手牌背面 |
| 中央 | 间合结晶一排（10 个菱形），两侧是双方区域 |
| 另一侧 | 我方集中力、我方手牌 |
| 角落 | **对方王牌区**：点开展示 3 张王牌，**已打出的翻正面、未打出的显示卡背** |
| 基本动作 | 前进 / 后退 / 缠绕 / 宿命 四个按钮 |

> 上一版我把「对方王牌区」和「对方头像」认混了，还猜成「投了」按钮——**全错**。这里更正。

### 4.2 我们自己场景的设计原则（待细化）

- 不照抄实体版图，重新设计
- 但**信息必须齐全**：双方的 装 / 气 / 命、间合、集中力、手牌、王牌区、付与区
- 区域**不标名字**（用户明确说要「虚」的感觉，但界面上不写文字标签）
- 视觉基调：樱、落花、俯视角

## 5. 四个关键动效（D23 + 本次修订）

| 动效 | 实现 |
| --- | --- |
| **可出牌提示** | 粉紫色光圈，呼吸动画，只标记真有合法出法的牌 |
| **出牌展示** | **俯视角下沿 Y 轴旋转数圈 + 放大**居中（不是简单平移放大）；双方同时可见 |
| **付与展开** | 打出后弹出「纳入结晶」：**从虚（尘）或装中取**，数量固定＝卡的「纳」；选完结晶飞上牌面 |
| **结晶移动** | **不要规整抛物线**——要像樱花飘落：带横向摆动、轻微旋转、速度不匀，落点前有个小减速 |

> 用户原话：「钱学森弹道」——意思是别给我走直线，要有诡异的滑翔感。这个可以做得好看。

## 6. 修正记录（v1 → v2）

| 项 | v1 错误 | v2 更正 |
| --- | --- | --- |
| 截图方向 | 当成竖屏读 | **竖屏截图、横屏游戏**，内容旋转 90° |
| 「?」头像 | 未解锁 | **随机选择** |
| 右上红色印章 | 猜是「投了」 | **对方角色头像**；「投了」不存在 |
| 红色数字 38/24 | 猜是卡组强度 | **选卡倒计时**，且我们不做计时 |
| 付与结晶来源 | 写了「气或尘」（错的） | **虚（尘）或装**（规则 §9-2-3 就是这么写的） |
| 出牌动效 | 位移+旋转放大 | **俯视角沿 Y 轴旋转数圈**再放大 |
| 结晶飞行 | 抛物线 | **樱花式飘落**，允许不规则 |
| 布局 | 桌面端重排 | **与移动端一致** |
