# 游戏流程参照（来自手机版实机截图）

> 来源：用户在手机上录屏后截取的 9 张实机画面（手机版，版本 2.0.9）
> 用途：作为 M1/M2 界面与交互的**参照基准**，不是照抄
> ⚠️ **截图本身不入库**（含官方美术），本文只做文字化描述

---

## 0. 四段流程

```
① 开始界面  →  ② 选人  →  ③ 组卡组  →  ④ 对战
```

桌面端比手机屏幕大得多，**所有布局都要重新算**，但信息层级可以照搬。

## 2. 选人界面（对应图 2、图 3）

实机看到的：

- **左侧两列六边形头像**，竖排铺满，是可选的**女神头像**（约 26 个，含一个「?」未解锁位）
- **右侧四个暗色六边形板** = 四个**槽位**，上下两组（看起来是「我方两柱 + 对方两柱」或「先选/后选」）
- 未选时四块板是空的，只显示暗纹
- **图 3**：选完后槽位里显示女神立绘，每块板右侧出现 **「变更」「移除」** 两个竖排按钮
- 图 3 里下方两块板还没选，上面两块已选（我方：摇波 + 另一柱；对方也已选）

### 桌面端方案

```
┌───────────────────────────────────────────────────┐
│  ← 返回                       选人（第 1/2 位）     │
├──────────────────────┬────────────────────────────┤
│  女神头像网格          │  我方                                │
│  ┌──┐┌──┐┌──┐┌──┐    │  ┌──────────┐ ┌──────────┐  │
│  │  ││  ││  ││  │    │  │  槽位 1  │ │  槽位 2  │  │
│  └──┘└──┘└──┘└──┘    │  └──────────┘ └──────────┘  │
│  ┌──┐┌──┐┌──┐┌──┐    │                             │
│  │  ││  ││  │└──┘    │  对方（联机时才显示）          │
│  └──┘└──┘└──┘        │  ┌──────────┐ ┌──────────┐  │
│                      │  │    ?     │ │    ?     │  │
│  悬停：显示女神名 + 关键词│  └──────────┘ └──────────┘  │
└──────────────────────┴────────────────────────────┘
```

- 头像**保留六边形**（这是辨识度很高的元素，也容易用 CSS `clip-path` 做）
- 悬停显示：女神名 + 专属关键词（决死/八相/连火/境地）
- 已选槽位右侧给「移除」小按钮；要换就点移除再选（比「变更」简单）
- **必须限制**：同编号异格不能同时选（D18 已经不做异格，所以四个基础女神之间没这个问题，但仍要保留校验逻辑）
- 选满 2 位 → 底部出现「下一步」按钮

- 联机时，对方选的柱子**立刻可见还是隐藏到最后**？（实机看起来是分上下两组同时显示）

## 3. 组卡组界面（对应图 4、图 5）

实机看到的：

- **左侧一竖排**是**已选入卡组的牌**（看起来 8 张，竖着排）
- **中间两列**是**可选卡池**（22 张里的剩余部分）
- **未选中的卡是灰的，已选的亮起来**（图 4 → 图 5 对比明显：图 5 里多了几张彩色卡）
- 鼠标移到某张卡上时，右侧会展示**放大的卡面 + 效果文字**
- 左侧有个竖排按钮 **「决斗へ」**（进入决斗）
- 右侧有红色数字 **「38」「24」**（含义待确认，可能是剩余可选数 / 卡组强度评估）

### 桌面端简化方案（按用户要求）

> 用户明确说：**不用做右侧预览，未选的全亮、已选的打个勾就行，能判断选没选即可。**

```
┌──────────────────────────────────────────────────────┐
│  ← 返回                组卡组        通常札 5/7  王牌 3/3 │
├──────────────────────────────────────────────────────┤
│  通常札（7 张）            王牌（3 张）                  │
│  ┌────┐┌────┐┌────┐     ┌────┐┌────┐┌────┐┌────┐   │
│  │斩 ✓││一闪 ││柄击 ✓│     │月影││浦波││浮舟││天音│   │
│  └────┘└────┘└────┘     └────┘└────┘└────┘└────┘   │
│  ┌────┐┌────┐┌────┐     （选 3 张，选满不能再选）        │
│  │居合││身法││气合│                                   │
│  └────┘└────┘└────┘                                   │
│                                                      │
│  [ 决 斗 ]   ← 7 张通常 + 3 张王牌都选满才亮             │
└──────────────────────────────────────────────────────┘
```

**规则约束**（来自 `docs/规则机制.md`）：

- 通常札：从两柱的 **14 张**里选 **7 张**
- 王牌：从两柱的 **8 张**里选 **3 张**
- 选满前「决斗」按钮置灰

交互细节：

- 点击卡片 = 选中/取消，选中显示**打勾 + 亮色**，未选是灰的
- 计数实时更新（`6/7`），选满后同区的其余卡片自动变灰锁定
- 不做右侧大图预览（省事，也符合「界面简洁」D13）

## 4. 对战界面（对应图 6–11）

### 4.1 整体布局（图 6）

实机看到的：

| 位置 | 内容 |
| --- | --- |
| 左上 | **对方的两位女神头像**（两个小六边形） |
| 左上角 | **集中力** 显示 `1/2`（对方的） |
| 顶部中 | 四个动作按钮：**後退 / 前進 / 纏(+?) / 宿(+?)** |
| 右上 | **对方手牌**（3 张背面，斜着排） |
| 右上角 | 一个红色印章（看起来是「敬」＝认输/投了） |
| 中央 | **战场板**：中间一排 10 个菱形结晶＝**间合**；四周是双方各自的区域 |
| 左下 | **我方集中力** `0/2` |
| 底部 | **我方手牌**（正面，横排） |
| 右下 | 我方两位女神头像 |

> 中间那块「板」本身就是游戏里的实体盘面：**间合在正中间一条线上，两侧分别是各方的 装 / 命 / 气 区域**，结晶就在上面移动。这跟实体桌游的盘面完全一致。

### 4.2 桌面端方案

```
┌─────────────────────────────────────────────────────────────┐
│  对方 ◇◇    集中力 1/2        [後退][前進][纏][宿]      手牌 ▤▤▤  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│        ┌───────────────────────────────────────────┐        │
│        │            对方： 装 ●●●   命 ●●●●●●●●●●   气 ●●  │        │
│        │  ───────────────────────────────────────  │        │
│        │   间合  ◇◇◇◇◇◇◇◇◇◇  (10 格)              │        │
│        │  ───────────────────────────────────────  │        │
│        │            我方： 装 ●●●   命 ●●●●●●●●●●   气 ●   │        │
│        └───────────────────────────────────────────┘        │
│                                                             │
│  我方 集中力 0/2    ◇◇                                   ◇◇   │
├─────────────────────────────────────────────────────────────┤
│  手牌： ┌──┐┌──┐┌──┐┌──┐┌──┐   ← 可出的牌有粉紫光圈          │
│         │斩││闪││柄││居││身│                                │
│         └──┘└──┘└──┘└──┘└──┘                                │
└─────────────────────────────────────────────────────────────┘
```

要点：

- **间合结晶横排在正中央**（原作就是盘面中轴），这是最重要的视觉锚点
- 双方区域**上下对称**：上方是对手（装/命/气），下方是自己
- 集中力用大圆章显示（原作是毛笔字「集中」，很有味道，可以用 CSS 画个类似的圆形）
- 基本动作做成 4 个按钮（前进/后退/缠绕/宿命），**离脱**放次要位置
- 手牌在底部横排，**能出的牌加粉紫光圈**（见 4.3）

### 4.3 可出牌提示（图 7）

> 有牌可以出时，手牌上会出现**粉紫色光圈**。

实现：给可用的卡片加 `box-shadow` 呼吸动画（粉紫色 `#d96b9e` 一类），局内节奏约 1.2s 一次。**只对当前真有合法出法的牌点亮**，不做「全部亮」的假提示。

### 4.4 出牌动画（图 8）

> 打出后**快速旋转放大**，居中展示，**双方可见**。

实现：

- 出牌瞬间：卡片从手牌位置 **位移 + 旋转 ±12° + 放大到屏幕中央**（约 350ms，ease-out）
- 停留约 **800ms**，然后缩回落点（弃牌堆/付与区/王牌区）
- 联机时：**房主广播「出牌」事件**，双方同时播；这是天然的同步点

### 4.5 付与牌的特殊流程（图 9、图 10）

> 付与牌展示完，会让你**选择要用的结晶数**，然后放在盘面上展示，直到结晶耗尽。

实机看到：屏幕中央有「请选择要使用的种结晶」提示，间合那一排上出现上下箭头（选数量），选完把结晶挪到牌上。

实现：

1. 出牌动画结束 → 弹出「纳入 X 个」选择（X = 这张牌的`纳`，可从**气**或**尘**取）
2. 选来源（气/尘）→ 结晶从来源**飞向付与牌**
3. 付与牌落在付与区，显示剩余结晶数
4. 每当结晶减少到 0 → 触发【破棄時】→ 卡进弃牌堆

> 注意：规则里「纳」是**固定数量**，不是自选数量。实机界面让玩家选的是「从哪些区域拿」（气/尘），不是拿几张。**这点要按规则来，别照抄 UI 文案。**

### 4.6 伤害动画（图 11）

> 受到任意伤害时，对应区域的结晶会**飘向应去的方向**。比如装受 1 点伤害，装上一个结晶会飘向「虚」。

实现：

- 结晶做**抛物飞行动画**（约 450ms），起点 → 终点，带轻微拖尾
- 目标区域高亮闪烁一下
- **数字跳字**：`-1` 从受击区域上方飘起
- 规则对应（见 `docs/规则机制.md` §5.1）：
  - 装受伤 → 结晶飞向**尘**
  - 命受伤 → 结晶飞向**气**
  - 气受伤 → 结晶飞向**尘**

> 实机图上标的「虚」＝规则里的「尘（ダスト）」，术语按 D19 统一叫**尘**。

## 5. 和手机版不一样的地方（我们主动简化）

| 项 | 手机版 | 我们 |
| --- | --- | --- |
| 登录 | 有「点击登录」 | 不要 |
| 设置 | 齿轮菜单 | 不要（先） |
| 组卡预览 | 右侧放大 + 效果文字 | **不要**，靠勾选状态判断 |
| 选人「变更」 | 变更 + 移除两按钮 | 只保留**移除** |
| 认输 | 右上角印章 | 保留，做成「投了」按钮 |
| 卡组强度数字 | 右侧 38/24 | 不要（看不懂，也不必要） |
| 竖屏 | 手机竖屏 | **横屏桌面布局**，上下分我方/对方 |
