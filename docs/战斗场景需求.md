## A. 场景要求（照做）

| 编号 | 要求 | 备注 |
| --- | --- | --- |
| **A1** | **整体中心对称（旋转 180°）** | 对战界面由双方版图构成；**先做一边，旋转复制，再修交界** |
| **A2** | **氛围＝「明亮的夜」** | 底色：蓝紫色暗调（参考参考图二：夜空、弯月、鸟居、发光樱枝）；标志性建筑用参考图三那座圆形神殿/塔楼；点缀**散发微光的物件**（樱花结晶、灯笼） |
| **A3** | **虚（原版中心大圆）→ 石头围成的圆形浅水潭** | 结晶进出时产生**涟漪** |

| **A5** | **装 → 五角形石桌** | 以虚为原点，**第四象限**，紧邻水潭；上面放 **5 颗**结晶 |

| **A7** | **气 → 大灯笼，挂在同一棵樱花树上** | 同样在第四象限，但**更偏 +X**，x 值大于装 |
| **A8** | 手牌区、牌组 | 位置与原版一致 |
| **A9** | 弃牌区 + 盖牌区 | **合并**成一处，放在牌组上方 |
| **A10** | 右下角边缘的**发光按键** | 点击后**三张王牌替换手牌区**展示，再点还原；功能和图标保留 |
| **A11** | 左下角：集中力 + 角色小头像 + **基础行动折叠** | 基础行动默认不可见；**点击集中力**才展开，供选择 |
| **A12** | 折叠省出的空间 | 放**正在使用的付与牌** |

## C. 我的理解与风险点（画之前先确认，画完对照）

| 编号 | 我的理解 | 风险 |
| --- | --- | --- |
| **C1** | 「第四象限」按**屏幕坐标**（y 向下）理解 → 原点在虚，第四象限 = **右下** | 若你按数学坐标（y 向上）理解，则第四象限是右上，整个布局会相反 ⚠️ |
| **C2** | 双方**共用同一个水潭**（虚在中心轴上，旋转 180° 后与自身重合） | 若你希望"两边各有自己的虚"，那就不叫中心对称了 ⚠️ |
| **C3** | 石桥的 10 块石头就是**间合的 10 格**，两端分别对应 0 和 10 | 方向（左 0 右 10，还是反过来）还没定 |
| **C4** | 「手牌区、牌组与原版位置一致」，由于原版是竖屏，这里理解为**相对位置一致**（手牌靠下、牌组靠左） | 需要看样品后再调 |
| **C5** | 命 10 颗 + 气灯笼都挂在同一棵树上，视觉上需要一条**横伸的长枝**来挂 | 可能和装（五角桌）挤，样品里先按你的坐标摆，看效果 |
