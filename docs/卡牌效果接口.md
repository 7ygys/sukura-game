# 卡牌效果接口说明

> 写一张新卡的效果时，看这一页就够了。
> 所有东西都在 `game/engine/effects.js` 里。

---

## 一、效果写在哪

```js
const cards = {
  "卡牌 id": {
    onAttack(state, who, ctx, card) {},   // 【常时】出攻击牌时改数值
    onAfterAttack(state, who, pd) {},     // 【攻击后】伤害结算完之后
    onBreak(state, who, attach) {},       // 【破弃时】付与札结晶耗尽时
    onUse(state, who, card) {}            // 【使用时】行动牌使用后
  }
}
```

四个时机对应官方规则的四种效果分类（9-1-1）：

| 时机 | 对应规则 | 什么时候触发 |
| --- | --- | --- |
| `onAttack` | 【常时】 | 攻击牌打出、生成攻击之前 |
| `onAfterAttack` | 【攻击后】 | 伤害结算完之后 |
| `onBreak` | 【破弃时】 | 付与札的结晶归零时 |
| `onUse` | 【使用时】 | 行动牌的效果环节 |

---

## 二、能直接调用的动作（`Engine.fx`）

写效果时**不要**自己改 state，用这些小函数：

| 函数 | 作用 |
| --- | --- |
| `fx.draw(state, who, n)` | 抽 n 张（自动处理焦燥） |
| `fx.gainFocus(state, who, n)` | 获得集中力（畏缩中会先解除畏缩） |
| `fx.loseFocus(state, who, n)` | 失去集中力 |
| `fx.gainFlare(state, who, n)` | 从虚取 n 颗结晶到气 |
| `fx.damage(state, who, aura, life, choice)` | 直接造成伤害（不走对应流程） |
| `fx.attack(state, who, {range, aura, life, noRespond, chokoku})` | 生成一次攻击（走完整流程） |
| `fx.moveCrystal(state, who, from, to, n)` | 搬结晶（dust/distance/aura/flare/life） |
| `fx.discardHand(state, who, n, filter)` | 弃手牌 |
| `fx.hideHand(state, who, n, filter)` | 把手牌盖成伏札 |
| `fx.reshuffle(state, who)` | 重组牌库（会先失去 1 点命） |
| `fx.stagger(state, who)` | 让对手畏缩 |
| `fx.ask(state, who, sourceId, prompt, options)` | 让玩家做选择 |

## 三、需要玩家做选择时

```js
// 1. 在效果里提问
"04-tokoyo-o-n-4": {                      // 詩舞
  onUse(state, who) {
    Engine.effects.fx.gainFocus(state, who, 1);
    Engine.effects.fx.ask(state, who, 'shibu', '选一项', ['aura_to_flare', 'dust_to_dist']);
  }
}

// 2. 在 choices 表里写每个选项做什么
choices.shibu = {
  aura_to_flare(state, who) { Engine.effects.fx.moveCrystal(state, who, 'aura', 'flare', 1); },
  dust_to_dist (state, who) { Engine.effects.fx.moveCrystal(state, who, 'dust', 'distance', 1); }
};
```

界面会自动弹出选择框，玩家点了之后引擎走 `resolveChoice`。

## 四、关键词

| 函数 | 条件 |
| --- | --- |
| `Engine.effects.kesshi(state, who)` | 决死：自命 ≤ 3 |
| `Engine.effects.hassou(state, who)` | 八相：自装 ≤ 1 |
| `Engine.effects.kyouchi(state, who)` | 境地：自集中力 = 2 |
| `Engine.effects.renka(state, who)` | 连火：本回合第 3 张以后的牌 |

---

## 五、几个容易写错的点

1. **攻击的装伤上限是 5**，除非带「超克」——引擎已经在 `playCard` 里处理。
2. **"本回合下一次攻击 +X/+Y"** 用 `p.buff`，出牌时会自动叠加并清空。
3. **命伤会把结晶送到气**，不是消失（规则 5-8-3-1）。
4. **给对手看的攻击**（`fx.attack`）会检查距离，距离不对直接取消。
5. **再起** 的条件写在 `revive` 表里，`tryRevive` 在回合开始和伤害结算后调用。
