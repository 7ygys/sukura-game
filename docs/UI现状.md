## 已实现的交互

| 操作 | 效果 |
| --- | --- |
| **拖牌到中间的虚圈里松手** | 出牌（旋转 1.5 圈 → 放大 → 停留 → 缩回） |
| 拖到圈外松手 | 缩回，不出牌 |
| 手牌悬停 | 整张抬起放大（本地动作，对方看不到） |
| 点王牌键 | 手牌区 ↔ 王牌区切换 |
| 按 **D** | 距离 5 ↔ 2（看「脱离」出现/消失） |
| 双击 / 空格 | 回合黑条：横向黑条从左刷入 → 停住显示"第 1 回合" → 向右退出 |
| 点水面/虚圈 | （旧版有涟漪，现在虚是圈不是水面，涟漪改用纯线条） |
