## 画面结构

| 位置 | 我方 | 对方（整体旋转 180°，朝向他） |
| --- | --- | --- |
| 状态栏 | 左下 | 右上 |

中间：**虚**（半透明白圈，包住距）、**距**（竖轨 10 格，当前值显示在两端）、扫过式回合提示。
右侧：牌组 / 弃牌 / 盖牌 三堆；右下角王牌切换键。

## 已实现的交互

| 操作 | 效果 |
| --- | --- |
| **拖牌到中间的虚圈里松手** | 出牌（旋转 1.5 圈 → 放大 → 停留 → 缩回） |
| 拖到圈外松手 | 缩回，不出牌 |
| 手牌悬停 | 整张抬起放大（本地动作，对方看不到） |
| 点王牌键 | 手牌区 ↔ 王牌区切换 |
| 按 **D** | 距离 5 ↔ 2（看「脱离」出现/消失） |
| 双击 / 空格 | 回合黑条：横向黑条从左刷入 → 停住显示"第 1 回合" → 向右退出 |
| 点水面/虚圈 | （旧版有涟漪，现在虚是圈不是水面，涟漪改用纯线条） |
| **悬停女神头像** | 弹出小窗，显示该女神的**被动关键词 + 说明**（摇波「决死」、细音「八相」） |
