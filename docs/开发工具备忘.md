# 开发工具备忘

## 自己截图（重要）

以前沙箱限制下跑不了浏览器，只能"画完给你看"。现在会话拿到完全权限后，可以用 **Edge 无头模式** 自己截图自检：

```powershell
$edge = 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'
$html = 'E:\...\散樱乱武\_work\scene_vXX.html'
$out  = 'E:\...\散樱乱武\_work\shot_vXX.png'
$uri  = 'file:///' + ($html -replace '\\','/' -replace ' ','%20')
$prof = Join-Path $env:TEMP ('edge_' + [guid]::NewGuid().ToString('N').Substring(0,6))
& $edge --headless=new --disable-gpu --no-first-run --user-data-dir="$prof" `
  --hide-scrollbars --allow-file-access-from-files `
  --window-size=1600,900 --virtual-time-budget=5000 `
  --screenshot="$out" "$uri"
```

要点：

| 参数 | 作用 |
| --- | --- |
| `--allow-file-access-from-files` | 允许 `file://` 页面读同目录的图片/视频 |
| `--virtual-time-budget=5000` | 让页面跑 5 秒虚拟时间再截（等动画/视频首帧） |
| `--user-data-dir=<临时目录>` | 避免和已开的 Edge 抢配置；用完可删 |
| `?t=秒` 查询参数 | 页面里已内置，可跳到视频指定时间再截 |

> 注意：**读不了 MP4 的画面**（WPF/ffmpeg 都被挡），但用 `<video>` 让浏览器播是可以的，截图能截到视频画面。

## 视频背景的几个坑

| 坑 | 现状 | 处理 |
| --- | --- | --- |
| 文件太大（986 MB / 4 分钟 / 34 Mbps） | 能播但吃内存 | 建议转码：10~20 秒循环、5~8 Mbps（需 ffmpeg） |
| 循环切点生硬 | 已做首尾亮度淡入淡出 | 可再上"双 video 交叉淡化" |
| 视频尾部不可控 | 4 分钟没必要全播 | 建议裁成一段循环 |
